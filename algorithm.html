実装 melody-generator の形式的記述

Created by Jounlai Cho (cho@heuron.com) ／ ヒューロン株式会社

本稿は、実時間で無限に生成されるヒーリング・ピアノ曲の生成系について、 その設計を形式的に記述する。中核となる主張は次の一点である。 旋律の美しさは音符ごとの逐次的な決定からは生まれず、 「あらかじめ美しいと保証された断片の有限集合」と「断片を配置する時間的構造」の 二層に分離したときに初めて制御可能になる。 前者は公有の名旋律125曲から帰納した統計に照らして 300,000 個の候補から 999 個を層化抽出することで構成し、後者は楽節構造・起伏曲線・声部配置の 制約充足として定式化する。生成は決定論的であり、6文字のシードが曲を一意に定める。

まず、この生成系が作る曲そのものを聴いてください（約60秒）

1問題設定と設計方針

目標は「途切れることなく生成され続け、かつ一曲ごとに情動的な起伏を持つ ピアノ独奏曲」である。この目標は、生成系に対して相反する二つの要求を課す。 一つは実時間性で、次の曲は前の曲が鳴り終わるまでに 組み上がっていなければならない。もう一つは大域的構造で、 提示・展開・頂点・回帰という数十秒スケールの設計が無ければ、 どれほど個々の音程が美しくても曲として聴こえない。

音符単位の逐次生成（マルコフ連鎖、あるいは自己回帰モデル）は前者を満たすが 後者を苦手とする。局所的な遷移確率は「次の音」を決められても、 「16小節後に最高音へ到達するために、いま何を提示しておくべきか」を表現しない。 本系では次の分離を採る。

  1. 断片層。2小節（8拍）の旋律断片を有限個あらかじめ生成し、 美しさの評価関数で選抜してカタログ化する。断片が満たすべき性質 （音程分布、跳躍後の埋め戻し、リズムの多様性）はここで一度だけ検査する。
  2. 構造層。実時間では断片を選んで並べるだけにする。 並べ方は楽節構造・起伏曲線・接続の滑らかさという制約で決まり、 個々の音符には触れない。

この分離により、実時間側の計算は「制約を満たす断片の集合から一つ引く」に還元される。 断片は 999 個、和音適合は事前計算済みなので、一曲（32小節）の組み立ては 実測で 6.5 ミリ秒、演奏イベントへの変換まで含めても同程度で完了する。

2記法

2.1音高空間

旋律は絶対音高ではなく通しスケール度数で表す。 度数 d ∈ ℤ は主音を 1 とし、 8 で1オクターブ上、15 で2オクターブ上になる。 旋法 m ∈ {major, minor} の音階を sm = (sm[0], …, sm[6]) とすると、 度数から半音への写像は

σm(d) = 12 ⁢ ⌊d-17⌋ + sm [(d-1)mod7] (1)

であり、主音の MIDI ノート番号を τ とすると実音は π(d) = τ + σm(d) で与えられる。 smajor = (0,2,4,5,7,9,11)、 sminor = (0,2,3,5,7,8,10)。

同じ度数列（断片 m0100）を、写像だけ替えて鳴らす。音符は1つも書き換えていない

この表現を採る理由は二つある。第一に、断片が調と旋法から独立になるため、 同じ断片を長調でも短調でも、どの調でも再利用できる。第二に、後述の ゼクエンツ（平行移動）が度数の加算という単純な演算になる。 半音単位で平行移動すると音階外の音が生じるが、度数単位ならば必ず音階内に留まる。

2.2断片

断片 f は音符の有限列である。音符 n = (d, β, δ, v) は度数・開始拍・音価・ベロシティを持ち、 β ∈ [0, 8)、すなわち2小節に収まる。 断片の音程列を

Δ(f) = ( d2-d1 , … , dk-dk-1 ) (2)

と書く。度数差 1 が2度（順次進行）、2 が3度、3 以上が4度以上の跳躍に対応する。

3コーパスからの帰納

評価関数の係数は恣意的に決めていない。公有の名旋律 125曲・1768音・1643音程 を採譜し、その統計に合わせている。 公有の判定は「作曲者の没年が1955年以前、または伝承曲」とした （収録曲の最も新しい没年は1952年、伝承曲は26曲）。旋法の内訳は長調93曲・短調32曲。

この分布から二つの量を定義する。順次進行率と、跳躍後の埋め戻し率である。

rstep(f) = |{i:|Δi|=1}| |Δ(f)| , rfill(f) = |{i:|Δi|≥2∧|Δi+1|=1}| |{i:|Δi|≥2}| (3)

コーパスの実測値は rstep = 0.691、 rfill = 0.624 である。後者は 「跳んだら順次で埋め戻す」という声楽由来の原則が、名旋律において 6割超という高い率で守られていることを示す。跳躍しっぱなしの線は歌えない。

3.1旋律型の抽出

コーパスの度数列から、相対形の n-gram を 旋律型として抽出する。長さ ℓ の 部分列 (di, …, di+ℓ-1) を 先頭を 0 に正規化した (0, di+1-di, …) で同一視し、出現頻度を重みとする。得られたのは 旋律型490種・終止形26種・舞い上がり型58種・リズム細胞147種である。

特に重要なのが「舞い上がり型」で、(0, 3, 2, 1) —— すなわち4度上行してから順次下降する形 —— を典型とする。 コーパス125曲中189回出現し、多くの曲でクライマックスの瞬間を作っている。

抽出した型を、相対度数のまま鳴らす（これが断片の材料になる）

4断片の生成と評価関数

4.1候補の生成

候補断片は、旋律型を連結して度数列を作り、リズム細胞を割り当てることで生成する。 連結は前の型の終点を次の型の始点として共有する。乱数は固定シードの mulberry32（32ビット状態の乗算・排他的論理和シフト系 PRNG）のみを使い、 Math.random は用いない。文字列のシードは FNV-1a で 32ビットへ畳む。したがって生成は完全に再現可能である。 候補数は N = 300,000。

4.2評価関数

断片 f の美しさスコアを次で定義する。 基準値 50 から出発し、各項を加える。P は非負の減点項、 D と R は符号付き（帯に入れば加点、外れれば減点）、 B と β は非負の加点項である。

S(f) = 50 - Pleap - Pspan + Ddens + Rrhythm + Bdist + ∑t∈T(f) βt (4)

ここで T(f) は断片が持つ情動タグの集合である。 Pspan は音域が12度を超えた分への減点 （6·(span − 12)+）、 Ddens は音数密度（音数÷8）が 0.9〜1.8 の帯にあれば +10、 0.7 を下回るか 2.2 を上回れば逸脱に比例した減点である。以下、主な項を示す。

跳躍への減点。度数差 a = |Δi| について

Pleap = ∑i [ 3⁢(ai-3)+ + 2⋅1[ai=0] + 10⋅1[ai-1≥4∧ai≥4] ] + 60⋅(rleap-0.1)+ (5)

(x)+ = max(x, 0)。 3度（a = 2）に減点が無いのは、表1の通り3度が名旋律で 最頻の跳躍だからである。減点は4度以上から始まり、連続跳躍と同方向の連続跳躍には 追加の減点を課す。rleap が コーパス実測値の2倍（10%）を超えると、超過分に比例して大きく減点する。

分布への加点は、コーパスの帯に入っているかどうかで与える。

Bdist = 12⋅1[rstep∈[0.6,0.8]] + 8⋅1[rthird∈[0.1,0.3]] + 10⋅1[rfill≥0.6] (6)

リズム項 Rrhythm は音価の種類数に対して {1 → −22, 2 → −8, 3 → +6, ≥4 → +12} を与える。 音価が1種類しかない断片は、音程がどれほど美しくても童謡に聴こえ、 曲の一節にはならない。ゆえに単独で最大の減点を課す。

5層化抽出によるカタログ構成

スコア上位から 999 個を採ると失敗する。評価関数は一つの尺度なので、 上位はどれも似た「優等生」になり、無限に聴けば必ず飽きる。 さらに致命的なのは被覆の欠落で、ある和音進行のスロットに 乗る断片が一つも無ければ、その進行を引いた曲は破綻する。

そこで選抜を制約付き部分集合選択として定式化する。候補集合 C（|C| = 300,000）から |X| = 999 を選ぶ。

maxX⊆C ∑f∈X S(f) s.t. |X∩Gj| ≥gj , |X∩Kl| ≤kl , |X∩Bq| ≥9 (7)

Bq はバケットで、 輪郭6種 × 緊張度5段階 × 終止クラス2種 = 60 の層に候補を分割したもの （うち10層は定義上必ず空になる）。Gj は 下限目標、Kl は 上限である。

表3　下限目標 Gj の例（全 90 件超のうち抜粋）
目標下限意図
step-ratio ∈ [0.6, 0.8]560名旋律の音程分布に入る帯

この問題は多重被覆問題を含むため NP 困難である。実装は貪欲法を採り、 順序に一つの工夫を置く。被覆系の目標を量的目標より先に埋める。 被覆系（リズム型・和音スロット）は互いに重ならない細かい枠であり、 量的目標（順次進行の帯・音数）はどの断片でも満たしうる。量から先に埋めると スコア上位の似た断片で 999 枠が尽き、被覆が埋まらない。逆順なら、 被覆のために採った断片が量的目標も同時に満たす。各ラウンドでは 未達目標を最も多く同時に満たす候補を優先する。

上限 Kl は下限より弱い。下限が上限に 阻まれた場合のみ上限を無視する（曲が破綻するより偏るほうがましである）。 結果として得られたカタログは、音数の中央値 8、範囲 6〜12 音である。

6和音適合の事前計算

断片が和音に乗るかを実時間で判定すると高くつく。999断片×和音語彙60種×2小節の 適合判定は実測で 329 ミリ秒かかり、これは組み立て全体（6.5 ミリ秒）の50倍にあたる。 そこで断片ごとに、和音語彙の全要素に対する適合を事前計算しておく。

和音記号 c の構成音のピッチクラス集合を PC(c) とする。小節 B（断片の前半または後半）が 和音 c に乗る条件を次で定義する。

fits(B,c) ⇔ (∃n∈B:pc(n)∈PC(c)) ∧ (∀n∈B: exp(n) ∧ pc(n)∉PC(c) ⇒ res(n) ) (8)

ここで

exp(n) ⇔ (β(n)mod2=0) ∨ (δ(n)≥1.5) res(n) ⇔ |dnext-d|≤1 ∧ pc(nnext)∈PC(c) (9)

すなわち、強拍にあるか長く伸びる音（exp、 「表に出ている音」）が非和声音であることは許すが、その場合は 次の音へ順次進行で和声音へ解決することを要求する。 これは対位法における掛留・倚音の扱いをそのまま計算可能な述語にしたものである。 弱拍の短い非和声音（経過音・刺繍音）には何も課さない。

断片 f について、和音語彙 Vm（長調33種・短調27種）の添字集合

Fm(j) (f) = { i : fits(Bj(f),Vm[i]) } , j∈{1,2} (10)

を JSON に保存する。実時間側は「進行のこの2和音に乗る断片」を 集合の所属判定だけで引ける。同様に、掛留が成立する和音の添字集合も併せて持つ。

添字で保存しているため、和音語彙の既存要素の順序は不変でなければならない。 途中に挿入すると、全断片の適合情報が別の和音を指す。追加は必ず末尾に行う。

7楽曲の組み立て

7.1形式

一曲は4つのセクション A, A′, B, A″ からなる。 各セクションは L 個のスロットに分かれ、 1スロットが1断片（2小節）に対応する。標準の32小節では L = 4。A, A′, A″ は同一の和音進行の 変形を用い、B だけが別の進行を引く。

セクション内部ではスロットに楽節役割 (a, a′, b, a″) を割り当てる。 a は自由選択、a′ と a″ は a のゼクエンツ、 b は a と対比する自由選択である。

7.2ゼクエンツ

平行移動作用素を次で定義する。

Tk(f) = {(d+k,β,δ,v):(d,β,δ,v)∈f} , 定義域 : ∀d:1≤d+k≤15 (11)
a を鳴らしたあと、a に続けて T₊₂(a) を鳴らす。リズムは同じまま2度上がる

リズムとベロシティは保存され、度数だけが動く。これが「同じ歌が続いている」 という感覚の実体である。移動量 k は セクションと役割ごとの優先順表から選ぶ。表は方向を持つ。

表4　移動量 k の優先順（先頭ほど優先）
セクションa′a″意図
A1, 2, −1, 3, −2, 01, 2, 3, −1, −2, 0静かに提示し少し上げる
A′1, 2, 3, −1, 02, 3, 1, −1, 0明確に上昇
B2, 3, 1, 4, 03, 4, 2, 1, 0頂点へ駆け上がる
A″−1, −2, 1, −3, 0−2, −3, −1, −4, 0下降して収める

k = 0 はどの表でも末尾に置く。0 は平行移動ではなく 完全反復であり、ゼクエンツではない。これを先頭に置くと、 和音が動いても旋律が1音も変わらない小節が量産される（実測では、 先頭に置いた実装で完全一致する2小節断片の28%がこれに由来していた）。

採用は乗る中の最初の1つではなく、次の辞書式順序の最小元とする。

( lift, ⌊ord/3⌋, cad, ord ) (12)

lift は登り坂で要求高度に届かないとき 1、ord は 表中の位置、cad は終止音の好ましさの順位である。 第2成分で ord を3ずつの段に丸めているのが要点で、 段の中では終止が、段をまたぐと方向が優先される。方向だけを優先すると 「a′ がひとまず答える」率が実測 82.8% → 53.4% に落ち、終止だけを優先すると A→A′ の上昇が消える。どちらか一方を選ぶと必ずもう一方が失われる。

7.3起伏曲線と音高の窓

スロット (σ, k)（セクション番号と位置）に対して 要求緊張度と音高の窓を与える。緊張度の素の値は

ρ(σ,k) = { 3+2k/k∗σ = 2, k < k* 5σ = 2, k = k* 3σ = 2, k > k* uσ+(wσ-uσ)⋅k/(L-1)それ以外 (13)

k* がクライマックスのスロットで、 L ≥ 3 のとき k* = L − 2、 それ以外は L − 1 である。 最後のスロットではなく一つ手前に置くのは、頂点のあとに着地を残すためである。 (u, w) は A: (1,2)、 A′: (2,3)、A″: (3,1)。

音高の窓は次で与える。peak(f) を断片の最高度数として、

pmax = { 14クライマックス 10A″ および頂点通過後 11それ以外 , pmin = { 12クライマックス 1それ以外 (14)

σm は狭義単調増加なので、 非クライマックスの上限 11 とクライマックスの下限 12 が交わらないことから、 曲全体の最高音がクライマックスのスロットにのみ現れることが構造的に保証される。 さらにクライマックスでは断片内の最高音が一度だけ（peakCount = 1） であることを要求するので、最高音は曲中でちょうど一度だけ鳴る。 涙腺に効くのは高さそのものではなく、そこで初めて届いたという一回性のほうである。

7.4クライマックスへの登り

上限だけを与えても、頂点の直前が低いままなら頂点は跳躍で到達される。 そこで登り坂のスロットに下限の好みを課す。

rise(2,k) = max(2, 10-(k∗-1-k) ) , 0<k<k∗ (15)

これは必須制約ではなく選好であり、満たす候補が空なら黙って諦める（後述）。 この一手で、頂点直前の小節の最高音が主音+12.5半音から+13.8半音へ上がり、 頂点との差は9.1半音から6.3半音へ縮んだ。

7.5選択のフィルタ列

スロットに置く断片は、まず必須条件（和音適合と音高の窓）で 候補集合 C0 を作り、次に 選好を順に適用して絞る。選好は単調な非空化フィルタである。

Ci+1 = { φi(Ci)φi(Ci)≠∅ Ciそれ以外 (16)

「該当が無ければ絞らない」というこの規則により、選好をいくつ重ねても 候補が空になることはなく、フォールバック断片へ落ちる確率は実測で 0 である。 適用順は効果の大きい順ではなく、候補が広いうちに掛けたい順である。

  1. 輪郭の対比（b は a と異なる輪郭・異なる打点列）
  2. 舞い上がり（クライマックスのみ）
  3. 登り（式15）
  4. 終止音の好み（役割ごと。a は開いたまま、a″ は主音）
  5. 息の流れ（フレーズ末は閉じ、途中は閉じない）
  6. 掛留（陰りの和音の上と頂点の直前）
  7. 五音音階（口ずさめること）

終止を五音音階や掛留より先に置くのは、あとに回すと絞られた小さな集合に 目当ての終止音が残っておらず素通りするからである。同じ理由で、 陰りの和音の上では掛留を五音音階より先に掛ける。

8転調

最終セクション A″ のみを新しい主音で描く。 和音記号は主音からの相対表記なので一つも書き換えない。動くのは τ だけであり、進行も楽節構造もゼクエンツも そのまま持ち上がる。上げ幅は s ∈ {1, 2} 半音。

上げ幅を機械的に半々で引くと、調号が遠く飛ぶ組み合わせが出る。 変ニ長調（フラット5つ）から +1半音 は ニ長調（シャープ2つ）で、 五度圏を7つ移動する最も遠い跳び方になる。同じ調でも +2半音 なら 変ホ長調（フラット3つ）で距離2に収まる。そこで五度圏上の位置を φ(τ, m) として距離を定義し、

d(s) = |φ(τ+s,m)-φ(τ,m)| , P(s) ∝ (1+d(s))-3 (17)

で抽選する。両方が遠い（d ≥ 5）ときは抽選せず近いほうに決める。 指数 3 は実測で選んだ。3,000回の抽選での平均距離と最悪距離（7）の出現率は次のとおり。

表6　上げ幅の重み付けと調号の移動距離（3,000回の抽選）
重み平均距離距離7距離10以上
半々で機械的に引く4.4319.5%6.1%
(1+d)−22.934.9%0.0%
(1+d)−3（採用）2.642.0%0.0%

指数をさらに上げると +1半音 がほとんど出なくなり、半音上げというバラードの 定石そのものが消える。

+1半音の転調は原理的にどうやっても調号が5つ以上動く（1半音 = 五度圏で7つ、 反対回りに5つ）。半音上げというバラードの定石を残す以上「全部が近い」にはできない。 ここで潰しているのは「5で済むのに7も動く」場合だけである。

接合部として B の最終小節を新しい調の属和音に 差し替える。いきなり半音上がると唐突なので、属和音を1小節挟むと耳が新しい調を 受け入れてから主和音へ着地する。ただしその小節がクライマックスのスロットに入る長さ （16小節）では置かない。スロットは2小節ひとかたまりなので、後半だけ調が変われば 頂点の音と別の音が同じ高さになりうる。式14が保証する一回性のほうが接合より優先される。

9声部の配置

断片は度数で書かれているので、実音への写像には主音が要る。伴奏・ベース・パッドは 和音から独立に生成される。ここで素朴な実装は絶対的な音域で 伴奏を配置するが、それは旋律がどこを歌っているかを見ていない。 実測では旋律の音の 33.8%（最大13半音）が伴奏かパッドに追い越されていた。 伴奏が旋律の上を横切ると主従が入れ替わり、旋律は埋もれる。

同じ8小節を、伴奏の置き方だけ替えて鳴らす（旋律が聴こえるかを比べてください）

小節 b における天井を旋律の最低音から定める。

C(b) = minn∈M(b) π(n) - Δ , Δ=2 (18)

和音 V = (v1 < … < vr) を天井の下へ収める。 許される操作はオクターブ移動と上声の省略の二つだけで、音名は絶対に変えない。 半音単位で押し込むと、その和音は別の和音になってしまう。 オクターブ移動量 j ∈ ℤ を次の費用関数で選ぶ。

J(j) = 1000⋅(v1+12j+w-C)+ + 10⋅out(j) + |v1+12j-vprev| (19)

w = vr − v1 は和音の広がり、 out(j) は通常音域からの逸脱量、 最終項は前小節との声部進行である。係数1000により天井の遵守が最優先となり、 次に通常音域、最後に滑らかさが効く。それでも収まらない場合は 上声を（最低2音を残して）省略する。

さらに、4拍伸びるパッドについては半音衝突を検査する。小節内で 表に出ている旋律音（式9の exp）と 半音関係にある構成音を落とす。

V′ = { v∈V : ¬∃n∈Mexp(b) [(v-π(n))mod12∈{1,11}] } (20)

アルペジオなら半音の摩擦は一瞬で消えるが、持続音は消えない。 たとえば IM7 の第7音は主音の半音下にあり、 旋律が主音を歌うあいだ鳴り続けると解決しないまま唸る。

重要なのは、この検査を強拍の半音衝突すべてに掛けてはならないことである。 式(20)を導入する前の内訳を見ると、強拍衝突559件のうち448件（80%）が非和声音で、 そのうち99%が次の音へ順次解決していた。これは掛留・倚音そのものであり、 本系が狙って作っている陰りである。潰すべきは残りの、 旋律が和声音であるのに濁っている111件だけであった。 導入後は事故が11件まで減り、残る衝突の98%は解決を伴う掛留である （衝突そのものの割合が表5で 20.1% → 9.8% にとどまるのはこのため。 掛留は減らしていない）。

10演奏設計

拍とベロシティの列は、そのまま鳴らせば機械的である。強弱の設計は 味付けではなく骨格であり、設定に関わらず常に適用する。 ベロシティは三層の積で与える。

v(β) = clamp( v0 ⋅ (1+ε) ⋅ L(β) ⋅ W(β) ⋅ K(β) ) (21)
同じ12小節を、強弱設計を掛けた場合と平らにした場合で鳴らす
  • L：セクションの基準レベル。 A: 0.85、A′: 0.95、 B: 1.10、A″: 0.80 → 0.55（線形に下降）。
  • W：フレーズ（8拍）内のスウェル。フレーズの最高音を山として 1 − 0.18·|p − q| / max(q, 1−q, 0.25)。
  • K：クライマックス曲線。頂点の8拍前から 0.88 → 1.20 へ上げ、 頂点直後4拍で 0.75 へ落とす。この落差が「サビの後の脱力」を作る。
  • ε：シード由来のベロシティ揺らぎ（±10%）。

時間方向にはテヌート（頂点音のみ 30ms 遅らせて音価を1.15倍）、 フレーズ末の呼吸（15ms）、クライマックス手前のためらい （2拍かけて最大0.1拍）、終盤2小節のリタルダンド（最大0.5拍）を掛ける。 いずれもシード由来の PRNG から決定論的に生成されるため、 同じ曲コードは演奏の揺らぎまで完全に再現する。

これらの設計は楽譜にも記号として書き出す。強弱記号・松葉・スラー・ テヌート・ペダル・rit. は、同じ L, W, K から 導出されるので、音と楽譜が別々に育つことはない。

既定音量どうしの比較で RMS は 6.4 dB 上がり、音量つまみを最大にしても 最悪ピークは −0.9 dBFS で歪まない。抑揚が広がったわけではない。 同じ音量（85）で比べれば修正の前後とも 12.2 dB で変わらず、既定値の 引き上げぶんを含めると 12.9 → 12.2 dB とわずかに狭まっている。 主張できるのは「音量を 6.4 dB 上げても抑揚をほぼ失わなかった」までである。

その「ほぼ失わなかった」を作っているのが圧縮点の位置である。利得だけを 3.0 倍してしきい値を −8 のままにすると、抑揚は 9.9 dB まで潰れる（表7の最下行）。 リミッタが音楽的なピークまで削るためで、しきい値を −3 へ上げると 突発的な山だけを受け止める動作に変わる。出力の天井を圧縮ではなく 一律の減衰で作っているのも同じ理由による。

12限界

  1. リズムの多様性は形式の算術に縛られる。 32小節でリズム型は7〜8種類しか現れない。これは a′, a″ が a のゼクエンツで リズムを保存することの直接の帰結（4スロットにつき2種類 × 4楽節グループ）であり、 崩せば「同じ歌が続いている」感覚ごと失われる。除去すべき欠陥ではない。
  2. モチーフの再登場は文字通りの反復である。 完全一致する断片の 58% はセクションをまたぐ再登場に由来する。 歌の1番・2番・最終番と同じ構造であり、変奏を加えるべきかは 様式の選択であって正誤の問題ではない。
  3. 頂点への最後の一歩は依然として跳躍である。 これは「4度以上跳び上がって着地し順次で降りる」という舞い上がり型の 明示的な要求によるもので、コーパスで189回観測された形でもある。 小節をまたぐ登りは改善したが、最後の跳躍そのものは設計として残している。
  4. 和声語彙は機能和声に閉じている。 借用和音とセカンダリードミナントまでは含むが、旋法的和声や 非機能的な進行は扱わない。断片の適合が度数で事前計算されているため、 語彙の拡張はカタログの再生成を伴う。

基于片段目录与乐段结构的
疗愈钢琴旋律自动生成

对 melody-generator 的形式化描述

Created by Jounlai Cho (cho@heuron.com) ／ Heuron 株式会社

本文形式化地描述一个实时、无止境地生成疗愈钢琴曲的系统。核心主张只有一点： 旋律之美并非来自逐音的顺次决定；只有把问题拆成两层—— 一组事先已保证其美感的有限片段，以及安放这些片段的时间结构——它才变得可控。 前者的做法是：以从125首公有领域名曲归纳出的统计为准绳，从300,000个候选中分层抽取999个； 后者则形式化为对乐段结构、起伏曲线与声部配置的约束满足。生成是确定性的， 六个字符的种子即可唯一确定一首乐曲。

1问题设定与设计方针

目标是「不间断地生成、且每一首都具有情感起伏的钢琴独奏曲」。 这对生成系统提出了两个彼此矛盾的要求。其一是实时性： 下一首必须在前一首奏完之前组装完毕。其二是全局结构： 若缺少呈示、发展、顶点、回归这种数十秒尺度的设计， 无论单个音程多么优美，听起来都不成其为一首乐曲。

以音符为单位的顺次生成（马尔可夫链，或自回归模型）满足前者，却不擅长后者。 局部的转移概率能决定「下一个音」，却无法表达 「为了在十六小节之后抵达最高音，现在应当呈示什么」。本系统采用如下拆分。

  1. 片段层。预先生成两小节（八拍）的旋律片段， 以美感评价函数筛选并编成目录。片段应当满足的性质 （音程分布、跳进后的填补、节奏的多样性）在此一次性检查完毕。
  2. 结构层。实时阶段只做「选取片段并排列」。 排列方式由乐段结构、起伏曲线与衔接的平滑度决定， 绝不触碰单个音符。

这一拆分把实时侧的计算归结为「从满足约束的片段集合中抽取一个」。 片段共999个、和弦适配已预先算好，因此组装一首（32小节）实测为 6.5 毫秒， 连同转换为演奏事件也大致相同。

2记法

2.1音高空间

旋律不以绝对音高、而以贯通音阶级数表示。 级数 d ∈ ℤ 以主音为 1， 8 高一个八度，15 高两个八度。 将调式 m ∈ {major, minor} 的音阶记为 sm = (sm[0], …, sm[6])， 则级数到半音的映射为

σm(d) = 12 ⁢ ⌊d-17⌋ + sm [(d-1)mod7] (1)

设主音的 MIDI 音符号为 τ，则实际音高为 π(d) = τ + σm(d)。其中 smajor = (0,2,4,5,7,9,11)、 sminor = (0,2,3,5,7,8,10)。

采用这一表示有两个理由。其一，片段因此独立于调与调式， 同一片段在大调、小调、任何调上都可复用。其二，后述的 模进（平行移动）化为级数上的简单加法。 若以半音平移会产生音阶外的音，而以级数平移则必然留在音阶之内。

同一级数序列（片段 m0100），只更换映射后播放。音符一个也没有改写

2.2片段

片段 f 是音符的有限序列。音符 n = (d, β, δ, v) 具有级数、起始拍、时值与力度， 其中 β ∈ [0, 8)，即收在两小节之内。 其音程序列记为

Δ(f) = ( d2-d1 , … , dk-dk-1 ) (2)

级数差为 1 对应二度（级进），2 对应三度，3 以上对应四度及以上的跳进。

3从语料库归纳

评价函数的系数并非随意设定。它们对齐于为此采谱的 125首公有领域名曲、1,768个音、1,643个音程的统计。 公有领域的判定标准为「作曲者卒于1955年以前，或为传承曲」 （收录曲中最晚的卒年为1952年，传承曲26首）。调式构成为大调93首、小调32首。

由这一分布定义两个量：级进比率，以及跳进之后被填补的比率。

rstep(f) = |{i:|Δi|=1}| |Δ(f)| , rfill(f) = |{i:|Δi|≥2∧|Δi+1|=1}| |{i:|Δi|≥2}| (3)

实测值为 rstep = 0.691、 rfill = 0.624。后者表明， 源自声乐的原则「跳进之后以级进填回」在名曲中以超过六成的高比率被遵守。 一味跳进的旋律线是唱不出来的。

3.1旋律型的抽取

从语料库的级数序列中，以相对形的 n-gram 抽取 旋律型。长度为 ℓ 的子序列， 以首位归零后的 (0, di+1-di, …) 视为同一，出现频次作为权重。由此得到 旋律型490种、终止型26种、飞扬型58种、节奏细胞147种。

其中尤为重要的是「飞扬型」，典型为 (0, 3, 2, 1)—— 即上行四度后级进下行。它在125首中出现189次， 在许多乐曲中造就了高潮的那一瞬间。

抽取出的旋律型本身，以相对级数直接播放（这是片段的原料）

4候选的生成与评价函数

4.1候选的生成

候选片段的生成方式是：把旋律型连接成级数序列，再为其分配节奏细胞。 连接时以前一型的终点作为下一型的起点共用。随机数只使用固定种子的 mulberry32（32位状态的乘法与异或移位 PRNG）， 不使用 Math.random；字符串种子以 FNV-1a 折叠为32位。 因此生成完全可复现。候选数为 N = 300,000。

4.2评价函数

片段 f 的美感分数定义如下。以基准值 50 出发，逐项相加。 P 为非负的扣分项，D 与 R 带符号（落在区间内加分，落在区间外扣分）， B 与 β 为非负的加分项。

其中 T(f) 为片段所带的情感标签集合。 Pspan 是音域超过十二度部分的扣分 （6·(span − 12)+）； Ddens 是音数密度（音数÷8）落在 0.9～1.8 区间时 +10，低于 0.7 或高于 2.2 时按偏离量扣分。以下列出主要各项。

对跳进的扣分，其中级数差 a = |Δi|：

S(f) = 50 - Pleap - Pspan + Ddens + Rrhythm + Bdist + ∑t∈T(f) βt (4)

其中 (x)+ = max(x, 0)。 三度（a = 2）不扣分，是因为如表1所示， 三度是名曲中最常见的跳进。扣分自四度起，连续跳进、 尤其是同方向的连续跳进另有追加扣分。当 rleap 超过语料实测值的两倍（10%）时， 超出部分按比例大幅扣分。

Pleap = ∑i [ 3⁢(ai-3)+ + 2⋅1[ai=0] + 10⋅1[ai-1≥4∧ai≥4] ] + 60⋅(rleap-0.1)+ (5)

分布的加分，依据是否落在语料库的区间之内。

Bdist = 12⋅1[rstep∈[0.6,0.8]] + 8⋅1[rthird∈[0.1,0.3]] + 10⋅1[rfill≥0.6] (6)

5以分层抽取构建目录

按分数取前999个会失败。评价函数是单一尺度，其上位因此清一色是「优等生」， 听得久了必然生厌。更致命的是覆盖的缺失： 若某个和弦进行的某个槽位上一个可用片段都没有，抽到该进行的乐曲便会崩坏。

于是把选拔形式化为带约束的子集选择。从候选集合 C（|C| = 300,000）中选出 |X| = 999 个。

maxX⊆C ∑f∈X S(f) s.t. |X∩Gj| ≥gj , |X∩Kl| ≤kl , |X∩Bq| ≥9 (7)

Bq 为分桶： 把候选按轮廓6种 × 紧张度5级 × 终止类2种 = 60 层划分 （其中10层依定义必然为空）。Gj 是 下限目标，Kl 是 上限。

该问题含有多重覆盖，因而是 NP 困难的。实现采用贪心法，并在顺序上下了一处功夫： 先填覆盖类目标，再填数量类目标。 覆盖类（节奏型、和弦槽位）是彼此不重叠的细小名额， 数量类（级进比率区间、音数）则几乎任何片段都能满足。 若先填数量类，999个名额会被分数靠前的相似片段耗尽，覆盖便填不满； 反过来，为覆盖而选入的片段会顺带满足数量类目标。 每一轮中优先选取能同时满足最多未达成目标的候选。

上限 Kl 弱于下限：仅当下限被上限阻挡时才忽略上限 （目录有所偏斜，总好过乐曲崩坏）。最终目录的片段音数中位数为 8，范围 6～12。

6和弦适配的预计算

实时判定片段能否配上某个和弦，代价很高。999片段 × 和弦语汇60种 × 2小节 的适配判定实测需 329 毫秒，是整曲组装（6.5 毫秒）的50倍。 因此逐片段预先算好其对和弦语汇全部元素的适配。

将和弦记号 c 的构成音音级集合记为 PC(c)，则小节 B （片段的前半或后半）能配上和弦 c 的条件定义为

fits(B,c) ⇔ (∃n∈B:pc(n)∈PC(c)) ∧ (∀n∈B: exp(n) ∧ pc(n)∉PC(c) ⇒ res(n) ) (8)

其中

exp(n) ⇔ (β(n)mod2=0) ∨ (δ(n)≥1.5) res(n) ⇔ |dnext-d|≤1 ∧ pc(nnext)∈PC(c) (9)

也就是说：位于强拍或时值较长的音 （exp，「浮在表面的音」）允许是和弦外音， 但此时要求它以级进解决到和弦内音。 这把对位法中对倚音、留音的处理直接化为可计算的谓词。 弱拍上时值短的和弦外音（经过音、辅助音）则不加任何限制。

对每个片段 f，把和弦语汇 Vm（大调33种、小调27种）的下标集合

Fm(j) (f) = { i : fits(Bj(f),Vm[i]) } , j∈{1,2} (10)

保存为 JSON。实时侧只需一次集合归属判定，即可取出「能配上这两个和弦的片段」。 留音成立的和弦下标集合亦同样保存。

由于保存的是下标，和弦语汇中既有元素的顺序绝不可改动。 中途插入会使全部片段的适配信息指向另一个和弦。新增必须追加在末尾。

7乐曲的组装

7.1曲式

一首乐曲由 A、A′、B、A″ 四个段落构成。 各段分为 L 个槽位，一个槽位对应一个片段（两小节）。 标准的32小节时 L = 4。 A、A′、A″ 使用同一和弦进行的变形， 只有 B 抽取另一个进行。

段落内部为各槽位分配乐段角色 (a, a′, b, a″)。 a 自由选取，a′ 与 a″ 是 a 的模进， b 亦为自由选取，但要求与 a 形成对比。

7.2模进

平移算子定义如下。

Tk(f) = {(d+k,β,δ,v):(d,β,δ,v)∈f} , 定义域 : ∀d:1≤d+k≤15 (11)

节奏与力度保持不变，只有级数移动。这正是「同一首歌仍在继续」这一感觉的实体。 平移量 k 从按段落与角色分列的优先顺序表中选取。 该表带有方向。

先只播放 a，再播放 a 接 T₊₂(a)。节奏不变，音高上行二度

k = 0 在任何一行都置于末尾。0 并非平移，而是 完全反复。若像早期版本那样把它放在首位， 就会量产出「和声在动而旋律一个音也不变」的小节—— 完全一致的两小节片段中有 28% 源于此。

所采用的量并非「第一个能配上的」，而是下述字典序下的最小元。

( lift, ⌊ord/3⌋, cad, ord ) (12)

其中 lift 在攀升槽位未达到要求高度时为 1， ord 是在表中的位次， cad 是终止音的可取程度排名。 关键在第二个分量：它把 ord 每三个归为一 档，档内由终止决定，跨档则方向取胜。 只优先方向，a′ 的「先给出回答」率实测从 82.8% 降到 53.4%； 只优先终止，A→A′ 的上行则消失。二者择一，必然失去另一者。

7.3起伏曲线与音高窗口

对槽位 (σ, k)（段落号与位置）给出要求的紧张度与音高窗口。 紧张度的原始值为

ρ(σ,k) = { 3+2k/k∗σ = 2, k < k* 5σ = 2, k = k* 3σ = 2, k > k* uσ+(wσ-uσ)⋅k/(L-1)其他 (13)

k* 是高潮所在的槽位：L ≥ 3 时为 L − 2，否则为 L − 1。 之所以放在最后一个的前一个，是为了在顶点之后留下着陆。 (u, w) 为 A: (1,2)、 A′: (2,3)、A″: (3,1)。

音高窗口如下，其中 peak(f) 为片段的最高级数。

pmax = { 14高潮 10A″ 及越过顶点之后 11其他 , pmin = { 12高潮 1其他 (14)

由于 σm 严格单调递增， 而非高潮的上限 11 与高潮的下限 12 互不相交， 全曲的最高音只出现在高潮槽位在结构上即得到保证。 此外高潮还要求片段内的最高音只出现一次，因此最高音在全曲中恰好只响一次。 打动人的并非高度本身，而是「在那里才第一次抵达」的一次性。

7.4攀向高潮

只给出上限还不够：若顶点之前一直很低，顶点就会以跳进抵达。 因此为攀升中的槽位施加下限的偏好。

rise(2,k) = max(2, 10-(k∗-1-k) ) , 0<k<k∗ (15)

这是偏好而非硬约束；若没有候选满足，系统会默默放弃（见下文）。 仅此一处改动，就把顶点前一小节的最高音从主音上方 12.5 个半音提高到 13.8 个， 并把最后一步的落差从 9.1 个半音缩小到 6.3 个。

7.5选取的过滤链

放入槽位的片段，先由硬性条件（和弦适配与音高窗口） 构成候选集合 C0， 再依次施加偏好加以收窄。偏好是单调的、不致空集的过滤器。

Ci+1 = { φi(Ci)φi(Ci)≠∅ Ci其他 (16)

由于这条「无匹配则不收窄」的规则，无论叠加多少偏好，候选都不会变空， 实测落入应急片段的概率为 0。施加顺序并非按效果强弱， 而是按希望在候选还宽时施加的先后。

  1. 轮廓的对比（b 与 a 在轮廓与击点序列上都不同）
  2. 飞扬（仅高潮）
  3. 攀升（式15）
  4. 终止音的偏好，按角色（a 保持开放， a″ 落在主音）
  5. 气息（乐句末收束，句中不收束）
  6. 留音（阴翳和弦之上，以及顶点之前）
  7. 五声音阶（可被哼唱）

把终止置于五声音阶与留音之前，是因为若放在后面， 被收窄后的小集合中已不再留有所需的终止音，过滤会悄然落空。 出于同样的理由，在阴翳和弦之上，留音先于五声音阶施加。

8转调

只有最后一段 A″ 以新的主音写成。 和弦记号是相对主音的表记，因此一个也不改写；移动的只有 τ，进行、乐段结构与模进都原样抬升。 上行幅度为 s ∈ {1, 2} 个半音。

若以掷硬币的方式各半抽取，就会出现调号相距极远的组合。 从降D大调（五个降号）上行1个半音落到D大调（两个升号）， 在五度圈上移动七格，是最远的跳法；同一调若上行2个半音则落到降E大调（三个降号）， 距离仅为二。将五度圈上的位置记为 φ(τ, m)， 则距离与权重定义为

d(s) = |φ(τ+s,m)-φ(τ,m)| , P(s) ∝ (1+d(s))-3 (17)

当两者都很远（d ≥ 5）时不再抽签，直接取较近者。 指数 3 由实测选定：3,000 次抽取的平均距离与最坏距离（7）的出现率如下。

指数再往上提，+1个半音便几乎不再出现， 而「上行半音」这一叙事曲的定式本身也就随之消失了。

作为衔接，把 B 的最后一小节替换为 新调的属和弦。骤然上行半音听来突兀， 插入一小节属和弦，耳朵便能先接受新调，再落到其主和弦上。 但当该小节会落入高潮槽位时（16小节的乐曲）则不放置： 槽位以两小节为一整体，若后半才换调，顶点的音与另一个音可能达到同一高度。 式14所保证的一次性，优先于衔接的平滑。

9声部的配置

片段以级数书写，因此映射为实际音高需要主音。伴奏、低音与铺底则各自独立地由和声生成。 朴素的实现以绝对音域配置伴奏，而这并未考虑旋律正在何处歌唱： 实测中旋律有 33.8% 的音被伴奏或铺底越过，最高达13个半音。 伴奏一旦横穿到旋律之上，主从关系便颠倒，旋律就被埋没。

同样的八小节，只更换伴奏的配置方式（请留意旋律是否听得清）

小节 b 的上限由旋律的最低音确定。

C(b) = minn∈M(b) π(n) - Δ , Δ=2 (18)

再把和弦 V = (v1 < … < vr) 收到上限之下。允许的操作只有八度移动与省略上方声部两种，音名绝不改变。 若以半音强行压低，该和弦就变成了另一个和弦。 八度移动量 j ∈ ℤ 由下述代价函数选定。

J(j) = 1000⋅(v1+12j+w-C)+ + 10⋅out(j) + |v1+12j-vprev| (19)

其中 w = vr − v1 是和弦的展开幅度， out(j) 是偏离常用音域的量，末项则是与前一小节的声部进行。 系数 1000 使遵守上限成为最优先，其次是常用音域，最后才是平滑度。 若仍收不下，则省略上方声部（至少保留两个音）。

此外，对延续四拍的铺底还要检查半音摩擦： 凡与该小节中浮在表面的旋律音（式9的 exp）成半音关系的构成音，一律去掉。

V′ = { v∈V : ¬∃n∈Mexp(b) [(v-π(n))mod12∈{1,11}] } (20)

分解和弦的半音摩擦转瞬即逝，持续音则不会消失。 例如 IM7 的第七音位于主音下方半音， 当旋律歌唱主音时，它便一直未获解决地拍打着。

要紧的是，这项检查不可施加于强拍上的所有半音冲突。 在引入式20之前的内訳中，强拍冲突559处里有448处（80%）是和弦外音， 其中99%都以级进解决到了下一个音。那正是留音与倚音—— 本系统刻意要造就的阴翳。该消除的只是余下的111处， 即旋律本身是和弦内音却依然浑浊的情形。改动之后事故降至11处， 余下的冲突中98%是带解决的留音。（表5中冲突比例只从 20.1% 降到 9.8%， 原因正在于此：留音并没有被减少。）

10演奏设计

拍点与力度若照原样奏出便是机械的。力度设计不是调味而是骨架， 因此无论设置如何都恒常施加。力度由三层的乘积给出。

v(β) = clamp( v0 ⋅ (1+ε) ⋅ L(β) ⋅ W(β) ⋅ K(β) ) (21)
  • L：段落的基准电平。 A: 0.85、A′: 0.95、 B: 1.10、 A″: 0.80 → 0.55（线性下降）。
  • W：乐句（8拍）内的涨落，以乐句最高音为峰： 1 − 0.18·|p − q| / max(q, 1−q, 0.25)。
  • K：高潮曲线。顶点前8拍由 0.88 升至 1.20， 顶点后4拍降至 0.75。这一落差造就「副歌之后的松弛」。
  • ε：源自种子的力度抖动（±10%）。
同样的十二小节，分别以施加力度设计与将其抹平的方式播放

在时间方向上施加保持音（仅顶点音，延后 30 毫秒并把时值乘以 1.15）、 乐句末的换气（15 毫秒）、高潮之前的迟疑（两拍内最多 0.1 拍）、 以及终段两小节的渐慢（最多 0.5 拍）。这些都由源自种子的 PRNG 确定性地生成， 因此同一曲目代码连演奏的抖动都能完全复现。

这些设计同样以记号写入乐谱。力度记号、渐强渐弱、连线、保持音、踏板与 rit. 都由同一组 L, W, K 导出， 声音与乐谱因此不会各自演变。

12局限

  1. 节奏的多样性受曲式的算术所限。 32小节中只出现七到八种节奏型。这是 a′ 与 a″ 作为 a 的模进而保留节奏所导致的直接结果 （每四个槽位两种，共四个乐段组）。若打破它， 「同一首歌仍在继续」的感觉也会随之消失。这不是应当消除的缺陷。
  2. 动机的再现是字面意义上的反复。 完全一致的片段中有 58% 源自跨段落的动机再现。 这与歌曲的第一段、第二段与最后一段是同一种结构； 是否应当加以变奏，属于风格的选择而非对错的问题。
  3. 通向顶点的最后一步依然是跳进。 这源自对「飞扬型」的明确要求——上行四度以上抵达后级进下行—— 该形态在语料库中被观测到189次。跨小节的攀升已有改善， 但最后的跳进本身是作为设计而保留的。
  4. 和声语汇闭合于功能和声之内。 借用和弦与副属和弦包含在内，但不涉及调式和声与非功能性进行。 由于片段的适配是以级数预先算好的，扩充语汇需要重新生成整个目录。
